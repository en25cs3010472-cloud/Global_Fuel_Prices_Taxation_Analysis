🌍 Global Fuel Prices and Taxation Trends (2020–2026)

📌 Project Overview

This project explores global fuel price trends, regional differences, estimated taxation, and subsidies from 2020 to 2026 through interactive data visualizations. It combines Tableau dashboard analysis with an interactive website to present insights in an accessible and professional format.

🎯 Project Objectives

•⁠  ⁠Analyze fuel price trends across years and fuel types.
•⁠  ⁠Compare fuel prices across countries and regions.
•⁠  ⁠Explore relationships between estimated tax shares, subsidies, and fuel prices.
•⁠  ⁠Compare estimated tax shares across income groups.
•⁠  ⁠Build interactive dashboards to support data exploration and stakeholder analysis.

📊 Key Visualizations

•⁠  ⁠Fuel Price Trends
•⁠  ⁠Country Price Ranking
•⁠  ⁠Regional Fuel Cost Comparison

🌐 Interactive Website

The website provides interactive charts, filters for year, region, fuel type, and income group, summary metrics, and CSV export functionality.

To run it locally, download the website files and open index.html in a web browser with an internet connection.

⚠️ Data Disclaimer

The dataset contains simulated demonstration data and does not represent verified historical fuel prices, taxation, or subsidy figures. The project is intended for educational purposes, visualization practice, and portfolio demonstration only.

🚀 Project Outcome

This project demonstrates practical skills in data visualization, exploratory analysis, dashboard design, and communicating data-driven insights for different stakeholders.
